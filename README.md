## 🚀 How to Run

### Method 1: One-Click Launch (Recommended)
Double-click `start-portfolio.bat` in this folder. It will start the streaming server and open your default browser at `http://localhost:3456`.

### Method 2: Command Line
```bash
node server.js
```
Then visit `http://localhost:3456` in any web browser.

### Method 3: Direct File Opening
You can also directly double-click `index.html` to open it locally in your browser.
